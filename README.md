# SGA en español - edición acumulativa

La versión `2026-08-21-r8` continúa la única línea española evolutiva de los
Séminaires de Géométrie Algébrique. El lector acumulativo enlazado tiene 2.873
páginas e incorpora una sola vez las ramas corregidas/actuales completas de
SGA 1, SGA 2, SGA 4, Tomo I, SGA 4, Tomo II, SGA 4, Tomo III, SGA 4½, SGA 5, SGA 6, SGA 7, Tomo I y SGA 7, Tomo II. Las ramas
diplomáticas disponibles se depositan como lectores separados.

SGA 4 Tomo I comprende LNM 269, Exposiciones I-IV, preliminares, bibliografía e
índices: 351 unidades traducidas, 610 operaciones de aparato, 847 etiquetas
únicas y 1.473 referencias internas resueltas. Sus ramas actual y diplomática,
fuentes/evidencia, manifiesto de publicación y manifiesto SHA-256 son los cinco
archivos numerados 24–28.
