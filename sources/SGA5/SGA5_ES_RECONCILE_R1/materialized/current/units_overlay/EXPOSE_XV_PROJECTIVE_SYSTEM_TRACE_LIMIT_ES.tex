Supongamos construidos los sistemas $(K'_\nu)$ y $(h'_\nu)$; se puede escribir entonces
\[
\Tr^*h_\nu=\Tr^*h'_\nu=\sum(-1)^i\Tr h_\nu'^i
\]
para todo $\nu\in\mathbb N$. Sean
\[
K'=\varprojlim_\nu K'_\nu,
\quad\text{y}\quad h'=\varprojlim_\nu h'_\nu
\]
(endomorfismo de $K'$). Se ve que $(\Tr^*h_\nu)_\nu$ es un entero $\ell$-ádico igual a $\sum_i(-1)^i\Tr h'^i$. Además, el sistema proyectivo $(K'_\nu)$ satisface la condición de Mittag--Leffler, y lo mismo ocurre con el sistema $(H^{i-1}(K'_\nu))_\nu$ para todo $i$; se sigue que
\[
H^i(K')\xrightarrow{\sim}\varprojlim_\nu H^i(K'_\nu)
\]
para todo $i$ (EGA $0_{\mathrm{III}}$ 13.2.3). En el caso que nos interesa, donde $K_\nu=\R\Gamma_X(F_\nu)$ y $h_\nu=h_{\R\Gamma_X(F_\nu)}$, se ve que $H^i(K')$ se identifica con $H^i(X,F)$, y que el endomorfismo de $H^i(K')$ definido por $h'$ se identifica con $h_{H^i(X,F)}$. Por consiguiente, se puede escribir
\[
\sum_i(-1)^i\Tr h'^i=
\sum_i(-1)^i\Tr h_{H^i(X,F)},
\]
y queda así demostrada la fórmula (2'') del enunciado.
